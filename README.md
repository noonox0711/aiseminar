# aiseminar

AI 세미나·라이브 자료 모음. 날짜 폴더마다 그날 자료가 들어 있고, 모두 비밀번호 잠금본(암호문)이다.

| 폴더 | 내용 | 공개 기간 |
|---|---|---|
| `260930/` | 원장일지 라이브 — 코덱스로 받고 클로드코드로 정리하기 (흐름 안내) | 2026-10-31까지 |
| `260930/llm/` | 원장일지 라이브 — LLM · 에이전틱 AI 슬라이드 | 2026-10-31까지 |
| `review/` | 세미나·라이브 후기 (누구나 쓰고 볼 수 있는 공개 페이지) | 계속 |

- 날짜 폴더에는 **빌드된 잠금본만** 올린다. 평문 원본과 빌드 스크립트는 저장소 밖에 둔다.
- `review/` 는 잠금 없는 공개 페이지다. 후기는 Firebase(seminar-96fc2)의 `reviews` 에 저장되고, 새 행사는 `review/index.html` 의 `EVENTS` 목록에 한 줄 추가한다.
- `_expire/<날짜>/` 에 있는 파일은 그 날짜(한국 시간)가 되면 `.github/workflows/expire.yml` 이 같은 경로에 덮어쓴다.
